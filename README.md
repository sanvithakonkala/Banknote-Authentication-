# Banknote Authentication

## Objective
To classify banknotes as genuine or forged using machine learning.

## Algorithms
1. Support Vector Machine (SVM)
2. K-Nearest Neighbors (KNN)
3. Artificial Neural Network (ANN)

## Platform
Google Colab

## Language
Python

## Libraries
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

## Dataset
Kaggle Banknote Authentication Dataset

## Evaluation
Accuracy, Precision, Recall, F1-score and Confusion Matrix.
